# online-team

온라인팀 회의 대시보드 (비공개)

## 원본 첨부파일

- 대화방 입력칸의 클립 → **첨부파일 첨부하기**. 파일당 20MB까지 원본 그대로 저장합니다.
- 캡처 이미지는 입력칸에 붙여넣거나 파일을 끌어다 놓아 첨부할 수 있습니다. 한 번에 30개까지 선택·추가하고 한 메시지로 보낼 수 있습니다. 업로드 진행 수와 개별 제거를 지원하며, 실패 시 원본과 이미 업로드한 파일 정보를 유지하여 재시도합니다.
- 원본은 연결된 Google Drive의 비공개 폴더에 저장하고, 시트에는 파일 정보만 기록합니다. 업로드와 읽기 모두 기존 보드 비밀번호 인증을 사용합니다.
- 대화 속 큰 미리보기와 보내기 전 이미지 모두 클릭하면 전체 화면 검토창이 열립니다. 같은 메시지 또는 첨부 대기 목록의 사진을 좌우 버튼·키보드 방향키로 넘깁니다. 모바일에서는 화면에 맞춤 상태에서 스와이프로 넘기고, 확대 중에는 끌어서 이동합니다. 현재 사진 번호와 전체 장수를 표시합니다. 화면 맞춤·100%·200% 버튼, 최대 800% 확대, 휠 확대, 드래그 이동, 모바일 두 손가락 확대를 지원합니다. 원본 해상도를 표시하며 **원본 다운로드**는 파일명과 바이트를 유지합니다.
- 앞뒤 사진을 각각 2장까지 미리 읽고, 받은 원본은 이 기기의 브라우저에 보관해 재사용합니다. 압축이나 리사이즈 없이 최대 80개·200MB·30일 범위로 보관하며, 브라우저 저장소를 사용할 수 없어도 열람은 가능합니다. 처음 보는 원본은 네트워크 전송 시간이 필요합니다.
- SHA-256을 업로드·다운로드 때 확인합니다. 실패하면 초안을 유지하고 같은 ID로 재시도합니다.

서버 업데이트: 현재 운영 중인 Apps Script `Code.gs`의 `doPost`에서 기존 KEY 검사 **다음**에 아래 두 경로를 추가하고, `ChatAttachments.gs`의 함수를 추가한 뒤 기존 웹 앱을 새 버전으로 배포합니다. 녹음·대화·회의록 등 기존 서버 코드는 유지합니다.

```js
if (b.type === 'attachmentUpload') return attachmentUpload(b);
if (b.type === 'attachmentRead') return attachmentRead(b);
```

## 화면 설정

- 대화방 제목과 뒤로가기, 고정 메시지 모아보기는 스크롤해도 상단에 남습니다.
- 각 메시지를 고정·해제하고, 그 메시지에 쓰레드 답글을 달 수 있습니다. 고정과 답글은 대화방 구성원에게 공유되며 기존 실시간 메시지 경로로 갱신됩니다.
- 사진은 최대 3개씩 병렬 전송하며 보낸 사람의 미리보기에는 이미 가진 원본을 재사용해 서버에서 다시 내려받지 않습니다.
- 메신저의 팀원 카드에는 프로필의 최신 한 줄 상태가 표시됩니다.
- **사용방법**에서 각 화면의 간단한 설명을 봅니다.
- **즐겨찾기 → 편집**에서 자주 쓰는 화면과 첫 화면을 설정합니다. 설정은 이 기기의 사용자 이름별로 저장됩니다. 기본 첫 화면은 **나의 보드**입니다.
- 새로고침하면 마지막 화면·대화방·쓰레드·보던 사진 번호와 작성 중인 메시지 문구로 돌아옵니다. 새 탭에서 처음 접속하면 설정한 첫 화면을 엽니다. 전송 전 선택한 파일은 새로고침 후 복원하지 않습니다.
- `?view=me` 링크는 나의 보드를 바로 엽니다.

검증: Playwright와 Chrome이 설치된 환경에서 `node tests/dashboard.cjs`. 실제 운영 대화방에 메시지를 쓰지 않고 저장 API를 모의하여 원본 바이트 보존, 재시도, 새로고침, 붙여넣기, 문서 첨부, PC·모바일, 뒤로가기, 화면 설정을 확인합니다.

화면 코드를 수정한 뒤 `node build.mjs`를 실행하여 `chat-photos.css`, `chat-photos.js`, `original-cache.js`, `image-review.js`, `message-threads.js`, `dashboard-ui.js`, `view-state.js`를 `index.html`에 포함합니다. 배포 페이지는 별도 스크립트 요청 없이 열립니다.
